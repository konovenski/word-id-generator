project: word-id-generator

description:
this project should generate 3-word id's. It should be a js library that fit in a single js file that could be included in a project. also the same library should be implemented in python

id format is:

{4 letter word}-{6 letter word}-{4 letter word}

you should generate a list of at least a 1000 words for every position, and those words should not be offensive, etc
there should be 3 lists, one for every position

there should be just one function exposed from the library without any arguments. zero customizability

also you should create 2 things:
- html page that will use js lib, with a text field and a bbutton that will regenerate id's
- python file that will regenerate if when i hit spacebar or enter or whatever you will decide. zero fancy stuff, no comments, etc
